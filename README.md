# Cover Detector

Aplicación para detectar covers y plagios musicales usando redes neuronales convolucionales (EfficientNet-B0 con Triplet Loss).

## Uso

1. Sube un archivo de audio (MP3, WAV, OGG, M4A, FLAC) o graba directamente desde el micrófono.
2. Pulsa **Analizar**.
3. La app devuelve las 5 canciones del dataset más similares con su porcentaje de coincidencia.
